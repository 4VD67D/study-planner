# Учебный планировщик
![Tests](https://github.com/4VD67D/study-planner/actions/workflows/tests.yml/badge.svg)

Программа для учёта учебных заданий: название, описание, срок сдачи, статус. Написана на Python (tkinter + SQLite), интерфейс на русском языке.

<!-- ![Скриншот программы](screenshot.png) -->

## Что нужно

- Windows 10/11 и Python 3.8 или новее с сайта [python.org](https://www.python.org/downloads/). При установке оставьте включённым компонент **tcl/tk and IDLE** (он включён по умолчанию) и отметьте **Add python.exe to PATH**.
- Больше ничего устанавливать не нужно: файл `requirements.txt` не требуется, программа использует только стандартную библиотеку Python.

## Запуск

1. Скачайте проект: на странице репозитория нажмите **Code → Download ZIP** и распакуйте архив в любую папку, например `C:\StudyPlanner`. Либо клонируйте репозиторий:

   ```
   git clone https://github.com/4VD67D/study-planner.git
   ```

2. Откройте файл `main.py` в IDLE и нажмите **F5** **или** откройте командную строку в папке проекта и выполните:

   ```
   python main.py
   ```

   (если команда `python` не найдена, попробуйте `py main.py`).
3. При первом запуске рядом с `main.py` автоматически создаётся файл базы данных `planner.db`. В нём хранятся все задания, при следующем запуске они загружаются автоматически.

Необязательно: можно указать другой файл базы: `python main.py D:\data\my.db`.

## Возможности

- добавление, изменение и удаление (с подтверждением) заданий;
- статусы «Не начато», «В процессе», «Выполнено»;
- поиск по названию (без учёта регистра);
- режимы просмотра «Просроченные» и «Ближайшие (7 дней)»;
- автоматическое сохранение после каждого действия;
- проверка вводимых данных и понятные сообщения об ошибках.

## Тесты

```
python -m unittest discover -s tests -v
```

## Резервная копия данных

Скопируйте файл `planner.db` (при закрытой программе) в надёжное место. Для восстановления положите копию обратно рядом с `main.py`.

## Состав проекта

| Файл                    | Назначение                                 |
|-------------------------|--------------------------------------------|
| `main.py`               | исходный код программы                     |
| `tests/test_planner.py` | автоматические тесты                       |
| `planner.db`            | база данных (создаётся при первом запуске) |

## Технологии

Python, tkinter, SQLite (только стандартная библиотека).
