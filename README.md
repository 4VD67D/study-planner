# Учебный планировщик

Программа для учёта учебных заданий: название, описание, срок сдачи, статус.
Написана на Python (tkinter + SQLite), интерфейс на русском языке.

## Что нужно

- Windows 10/11 и Python 3.8 или новее с сайта <https://www.python.org/downloads/>.
  При установке оставьте включённым компонент **tcl/tk and IDLE** (он включён по умолчанию)
  и отметьте **Add python.exe to PATH**.
- Больше ничего устанавливать не нужно: файл `requirements.txt` не требуется,
  программа использует только стандартную библиотеку Python.

## Запуск

1. Распакуйте архив в любую папку, например `C:\StudyPlanner`.
2. Откройте файл `main.py` в IDLE и нажмите **F5**
   **или** откройте командную строку в папке проекта и выполните:

   ```
   python main.py
   ```

   (если команда `python` не найдена, попробуйте `py main.py`).
3. При первом запуске рядом с `main.py` автоматически создаётся файл базы данных `planner.db`.
   В нём хранятся все задания, при следующем запуске они загружаются автоматически.

Необязательно: можно указать другой файл базы: `python main.py D:\data\my.db`.

## Возможности

- добавление, изменение и удаление (с подтверждением) заданий;
- статусы «Не начато», «В процессе», «Выполнено»;
- поиск по названию (без учёта регистра);
- режимы просмотра «Просроченные» и «Ближайшие (7 дней)»;
- автоматическое сохранение после каждого действия;
- проверка вводимых данных и понятные сообщения об ошибках.

## Тесты

```
python -m unittest discover -s tests -v
```

## Резервная копия данных

Скопируйте файл `planner.db` (при закрытой программе) в надёжное место.
Для восстановления положите копию обратно рядом с `main.py`.

## Состав проекта

| Файл | Назначение |
|------|-----------|
| `main.py` | исходный код программы |
| `tests/test_planner.py` | автоматические тесты |
| `planner.db` | база данных (создаётся при первом запуске) |
